# app_pwa_ig (UTEQGram)

Aplicación Web Progresiva (PWA) de ejemplo desarrollada con JavaScript, Material Design Lite y Firebase Realtime Database.

## 🚀 Requisitos y Ejecución Local

1. Instalar dependencias:
   ```bash
   pnpm install
   ```

2. Iniciar el servidor local:
   ```bash
   pnpm start
   ```
   Abrir en el navegador: [http://127.0.0.1:8080](http://127.0.0.1:8080)

## 📱 Instalar como PWA en iPhone (iOS / Safari)

1. Abre el enlace desplegado (en Vercel con HTTPS) desde el navegador **Safari** en tu iPhone.
2. Toca el botón **Compartir** (icono de cuadro con flecha hacia arriba en la barra inferior).
3. Desplázate hacia abajo y selecciona **"Agregar a pantalla de inicio"** (*Add to Home Screen*).
4. Confirma el nombre (**UTEQGram**) y pulsa **Agregar**.
5. ¡Listo! La aplicación aparecerá en tu pantalla de inicio como una app nativa independiente con su propio icono y sin la barra del navegador.

## ☁️ Despliegue en Vercel

El proyecto incluye `vercel.json` configurado con `"outputDirectory": "public"`.
Puedes importar directamente el repositorio desde tu cuenta de Vercel y desplegará automáticamente.
